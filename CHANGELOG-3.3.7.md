# WildFollowers 3.3.7

Adds FOLLOWERS MARCH SPEED and WILDS MARCH SPEED next to their respective march toggles in the WildFollowers menu. Each independently offers 50%, 75%, 100%, 125%, 150%, 200%, and 300%; 100% is the existing eight-animation-frames-per-second rate. Settings persist through the normal mod and cartridge options system.

A shared frame selector keeps 2D and native/3D poses synchronized. March speed changes standing march animation and follower animation while march is enabled. Moving wilds retain their complete movement-step animation. March OFF preserves the existing animation behavior. These settings do not change movement speed, spacing, or catch-up behavior.

Validation: 2,214 targeted checks cover every speed, independent wild/follower selection, matching 2D/native frames, stationary coordinates, disabled march behavior, and existing spacing/overlap checks across Gen 1/2/3. Native options persistence and the full runtime fixtures pass for all eleven supported games.

Restart the game to load the new menu options.
