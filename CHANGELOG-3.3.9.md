# WildFollowers 3.3.9

FOLLOWERS MARCH SPEED and WILDS MARCH SPEED now apply only while stationary, including spacing-paused steps. When moving, followers use their normal eight-frame-per-second walking animation; wilds retain their normal movement-step animation. Saved march speed choices still control standing animation.

Validation: every speed choice is checked while walking and stationary in both 2D and native/3D poses across Gen 1/2/3. Full runtime and menu persistence fixtures pass across all eleven supported games.

Restart the game to load the change.
