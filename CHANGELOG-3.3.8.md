# WildFollowers 3.3.8

Adds 10%, 20%, 25%, and 33% choices to both FOLLOWERS MARCH SPEED and WILDS MARCH SPEED. Existing 50%–300% choices and saved settings are retained. The 10% minimum is 0.8 animation frames per second, completing a four-frame march cycle in five seconds.

Validation: all eleven speed choices tested independently in 2D and native/3D poses across Gen 1/2/3, with samples long enough to exercise the slowest cycle. Full runtime and native menu persistence tests pass across all eleven supported games.

Restart the game to load the new slower options.
